# JSON 编辑器设计文档

**日期**: 2026-04-17
**功能**: 请求构造器 Raw 类型的 JSON 格式化、行号显示、语法高亮

## 概述

为请求构造器的 Body -> Raw -> JSON 模式添加：
1. 手动 JSON 格式化功能
2. 独立行号列
3. 语法高亮显示

## 组件结构

```
JsonEditor (主组件)
├── 行号列 (LineNumbers)
│   ├── 固定宽度 (40px)
│   ├── 同步滚动
│   └── 行号渲染
├── 编辑区域 (Editor)
│   ├── Input 组件（用于文本输入）
│   └── 语法高亮装饰层
└── 工具栏
    └── Format 按钮
```

## 核心特性

### 1. 手动格式化

- 点击 "Format" 按钮格式化 JSON
- 使用 Rust 的 `serde_json` 进行解析和美化输出（缩进 2 空格）
- 非 JSON 格式时显示错误提示（红色文字）
- 格式化成功后更新编辑器内容

### 2. 行号显示

- 独立列显示行号（宽度 40px）
- 随编辑区域同步滚动
- 行号与内容行一一对应
- 行号颜色：灰色 (#666666)

### 3. 语法高亮

| 元素 | 颜色 |
|------|------|
| 字符串 | 绿色 (#22c55e) |
| 数字 | 橙色 (#f97316) |
| 关键字 (null/true/false) | 蓝色 (#3b82f6) |
| 括号 { } [ ] | 白色 (#ffffff) |
| 属性名 | 浅蓝色 (#38bdf8) |

### 4. 交互

- 编辑时实时更新行号
- 格式化时保留光标大致位置
- 错误状态显示在编辑器下方

## 实现位置

新建文件：`src/ui/json_editor.rs`

## 实现步骤

1. 创建 `JsonEditorState` 状态结构
2. 创建 `JsonEditor` 组件
3. 实现行号列渲染
4. 实现语法高亮渲染
5. 实现 Format 按钮和格式化逻辑
6. 集成到 main_view.rs 的 Body -> Raw -> JSON 部分

## 依赖

- `serde_json` - JSON 解析和格式化（已有）
- gpui 框架的布局和组件

## 兼容性

替换 `main_view.rs` 中的现有 Raw JSON 编辑器部分，不影响其他 Raw 格式（XML、Text、HTML、JavaScript）
